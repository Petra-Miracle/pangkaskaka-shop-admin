# SOP STREETBARBER PANGKASKAKA

**Standar Operasional Prosedur StreetBarber**

---

## TUJUAN

Memastikan setiap StreetBarber memberikan layanan yang bersih, rapi, sopan, lengkap, dan profesional kepada pelanggan PangkasKAKA.

---

## BAGIAN 1: KEBERSIHAN

### 1.1 Kebersihan Diri StreetBarber

- [ ] Mandi dan gunakan pakaian bersih sebelum melayani pelanggan
- [ ] Rambut tersisir rapi dan bersih
- [ ] Kuku bersih dan terpotong rapi
- [ ] Gunakan deodoran dan parfum ringan (tidak menyengat)
- [ ] Gigi bersih, tidak ada bau mulut

### 1.2 Kebersihan Pakaian

- [ ] Kaos/shirt bersih dan tidak lusuh
- [ ] Celana bersih dan tidak ada noda
- [ ] Sepatu/footwear bersih
- [ ] Tidak menggunakan pakaian dengan logo atau tulisan yang tidak pantas

### 1.3 Kebersihan Alat

- [ ] Semua alat dibersihkan sebelum dan sesudah digunakan
- [ ] Gunakan disinfektan untuk membersihkan alat
- [ ] Alat disimpan dalam wadah yang bersih
- [ ] Handuk/kain bersih dan baru untuk setiap pelanggan
- [ ] Kuas cukur dibersihkan dari sisa rambut

---

## BAGIAN 2: KERAPIHAN

### 2.1 Penampilan

- [ ] Pakaian kompak dan seragam (jika ada)
- [ ] Tidak ada barang yang menonjol di saku
- [ ] Tas/ransel tersusun rapi
- [ ] Alat terorganisir dalam tas/wadah

### 2.2 Peralatan

- [ ] Gunting tersusun berdasarkan ukuran
- [ ] Alat cukur (clipper) dalam kondisi rapi
- [ ] Aksesories (sanggul, jepit, dll) tersusun rapi
- [ ] Kabel alat tidak kusut

### 2.3 Area Kerja

- [ ] Bersihkan area setelah selesai melayani
- [ ] Buang rambut ke tempat sampah
- [ ] Kembalikan posisi alat ke tempat semula
- [ ] Pastikan tidak ada sisa rambut di lantai

---

## BAGIAN 3: KESOPANAN

### 3.1 Komunikasi

- [ ] Sapa pelanggan dengan ramah: "Selamat pagi/siang/sore, saya StreetBarber PangkasKAKA"
- [ ] Gunakan bahasa Indonesia yang sopan
- [ ] Hindari kata-kata kasar atau tidak pantas
- [ ] Dengarkan permintaan pelanggan dengan seksama
- [ ] Jelaskan proses yang akan dilakukan dengan jelas

### 3.2 Sikap

- [ ] Tersenyum dan bersikap ramah
- [ ] Tidak terburu-buru dalam melayani
- [ ] Sabar menghadapi permintaan pelanggan
- [ ] Tidak mengkritik penampilan pelanggan
- [ ] Menjaga etika profesional sepanjang waktu

### 3.3 Penghormatan

- [ ] Hormati privasi pelanggan
- [ ] Tidak menanyakan hal yang bersifat pribadi
- [ ] Mintai izin sebelum melakukan hal tertentu
- [ ] Ucapkan terima kasih setelah selesai melayani
- [ ] Pamitan dengan sopan: "Terima kasih, semoga harinya menyenangkan"

---

## BAGIAN 4: KELENGKAPAN ALAT

### 4.1 Alat Wajib

- [ ] Gunting potong (2-3 ukuran)
- [ ] Gunting sisir
- [ ] Alat cukur elektrik (clipper) + baterai充电 penuh
- [ ] Pisau cukur (safety razor)
- [ ] Kuas cukur
- [ ] Kaca kecil
- [ ] Sisir (2-3 jenis)
- [ ] Handuk bersih (minimal 2)
- [ ] Botol semprot air

### 4.2 Perlengkapan Tambahan

- [ ] Kain penutup/pelindung baju
- [ ] Kapur/krim cukur
- [ ] Aftershave/balsem
- [ ] Minyak rambut/pomade
- [ ] Hair dryer (jika diperlukan)

### 4.3 Peralatan Keamanan

- [ ] Masker kain (untuk pelanggan jika diminta)
- [ ] Hand sanitizer
- [ ] Sarung tangan (untuk layanan tertentu)
- [ ] Kotak P3K mini

### 4.4 Pengecekan Sebelum Berangkat

- [ ] Semua alat tersedia dan berfungsi
- [ ] Baterai alat充电 penuh
- [ ] Tas dalam kondisi rapi
- [ ] Tidak ada alat yang rusak atau tumpul

---

## BAGIAN 5: INTERAKSI DENGAN PELANGGAN

### 5.1 Sebelum Layanan

- [ ] Konfirmasi jadwal dan lokasi dengan pelanggan
- [ ] Datang 5-10 menit sebelum waktu yang ditentukan
- [ ] Hubungi pelanggan saat tiba di lokasi
- [ ] Perkenalkan diri dan tunjukkan identitas PangkasKAKA

### 5.2 Selama Layanan

- [ ] Tanyakan preferensi gaya rambut pelanggan
- [ ] Jelaskan hasil yang akan dicapai
- [ ] Berikan saran jika diperlukan (tanpa memaksa)
- [ ] Komunikasikan jika ada kendala
- [ ] Pastikan pelanggan nyaman selama proses

### 5.3 Setelah Layanan

- [ ] Tanyakan apakah pelanggan puas dengan hasil
- [ ] Bersihkan area dari sisa rambut
- [ ] Kembalikan semua alat ke tempat
- [ ] Minta review/penilaian dari pelanggan
- [ ] Informasikan layanan lain yang tersedia

### 5.4 Penanganan Keluhan

- [ ] Dengarkan keluhan dengan tenang
- [ ] Minta maaf jika ada kesalahan
- [ ] Tawarkan solusi yang tepat
- [ ] Hubungi admin jika keluhan tidak bisa diselesaikan
- [ ] Dokumentasikan keluhan untuk perbaikan

---

## CATATAN PENTING

1. **Konsistensi** — Terapkan standar ini untuk SETIAP pelanggan tanpa terkecuali
2. **Peningkatan** — Selalu cari cara untuk meningkatkan kualitas layanan
3. **Umpan Balik** — Terima kritik dan saran dengan terbuka
4. **Pelatihan** — Ikuti pelatihan yang diadakan oleh PangkasKAKA
5. **Pelaporan** — Laporkan masalah kepada admin segera
6. **TANPA PENGEMBALIAN DANA** — Setelah layanan berhasil dilakukan, TIDAK AKAN ada pengembalian dana (refund). Pastikan pelanggan memahami ini sebelum memulai layanan. Jika ada ketidakpuasan, tawarkan perbaikan/retouch, bukan pengembalian dana.

---

## PERATURAN DISIPLIN

Pelanggaran terhadap SOP ini dapat mengakibatkan:
- **Peringatan Lisan** — Untuk pelanggaran ringan pertama
- **Peringatan Tertulis** — Untuk pelanggaran berulang
- **Penangguhan** — Untuk pelanggaran serius
- **Pemecatan** — Untuk pelanggaran yang sangat serius
